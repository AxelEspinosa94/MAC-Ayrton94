## 2. History of Computer Graphics

### Definition 2.1 — Computer Graphics
Computer graphics is the field of study that focuses on the generation, manipulation, and representation of visual content using computational techniques.

### Key Milestones
- **1963 — Sketchpad (Ivan Sutherland)**  
  Considered the birth of interactive computer graphics. Introduced direct manipulation and graphical user interfaces.

- **1970s — Raster graphics and framebuffers**  
  Transition from vector displays to raster displays enabled pixel‑based rendering.

- **1980s — Standardization (PHIGS, GKS)**  
  First graphics standards for portability across systems.

- **1990s — OpenGL and real‑time 3D**  
  Hardware acceleration becomes mainstream.

- **2000s–present — GPUs and programmable pipelines**  
  Shaders, GPGPU, real‑time global illumination, and physically based rendering.

## 3. Classification of Computer Graphics

### Definition 3.1 — Raster Graphics
A representation of images as a grid of pixels.  
Common in displays, digital images, and real‑time rendering.

### Definition 3.2 — Vector Graphics
A representation of images using geometric primitives (lines, curves, polygons).  
Resolution‑independent; used in CAD, SVG, and illustration software.

### Definition 3.3 — 2D Graphics
Graphics restricted to two dimensions. Includes UI rendering, sprites, diagrams, and typography.

### Definition 3.4 — 3D Graphics
Graphics involving three‑dimensional objects, transformations, lighting, and projection.

### Definition 3.5 — Interactive vs. Non‑Interactive Graphics
- **Interactive:** User input affects the rendered output in real time.  
- **Non‑interactive:** Precomputed or static images (e.g., offline rendering).

## 4. Applications of Computer Graphics

### Definition 4.1 — Rendering
The process of generating an image from a model using algorithms for lighting, shading, and projection.

### Common Application Areas
- **Entertainment:** Video games, animation, VFX.  
- **Scientific Visualization:** Medical imaging, simulations, data visualization.  
- **Engineering:** CAD, CAM, architectural visualization.  
- **User Interfaces:** Operating systems, mobile apps, dashboards.  
- **Virtual and Augmented Reality:** Immersive environments and real‑time tracking.  
- **Education and Training:** Simulators, interactive learning tools.

## 5. Elements of a Typical Graphics Environment

### 5.1 Hardware Components

#### Definition 5.1 — Graphics Processing Unit (GPU)
A specialized processor optimized for parallel operations required in graphics rendering.

#### Definition 5.2 — Framebuffer
A memory buffer that stores the pixel data of the final rendered image.

#### Definition 5.3 — Input Devices
Devices used to interact with the graphics system:
- Keyboard  
- Mouse  
- Stylus  
- Touchscreen  
- Motion sensors  

#### Definition 5.4 — Output Devices
Devices that display or project graphical content:
- Monitors  
- VR headsets  
- Projectors  
- Printers  

---

### 5.2 Software Components

#### Definition 5.5 — Graphics API
A software interface that provides functions for rendering graphics.  
Examples: **OpenGL**, **DirectX**, **Vulkan**, **WebGL**.

#### Definition 5.6 — Graphics Standards
Specifications that ensure portability and consistency across systems.  
Examples: **GKS**, **PHIGS**, **OpenGL standard**, **ISO/IEC standards**.

#### Definition 5.7 — User Interface (UI)
The layer that allows users to interact with graphical applications through windows, menus, icons, and events.

---

### 5.3 Applications in a Graphics Environment
According to the syllabus:

> “1.4.3 Applications of computer graphics include modeling, simulation, visualization, and interactive systems.”

Examples:
- 3D modeling software (Blender, Maya)  
- Game engines (Unity, Unreal Engine)  
- Visualization tools (Matplotlib, ParaView)  
- Simulation environments (physics, robotics, weather)

---

## 6. Summary of Key Concepts

- Computer graphics evolved from vector displays to modern GPU‑accelerated pipelines.  
- Graphics can be classified by dimension (2D/3D), representation (raster/vector), and interaction.  
- Applications span entertainment, engineering, science, and UI design.  
- A graphics environment includes hardware (GPU, framebuffer, input/output devices) and software (APIs, standards, UI frameworks).
